## Эксперименты

| № | Прогноз | Факт | Объяснение |
|---|---|---|---|
| 1. Отсутствующий элемент и коллекция | `null` и `0` | `Отсутствующий элемент: null`, `Пустая коллекция: 0` | `querySelector` без совпадения даёт `null`, `querySelectorAll` — пустую коллекцию длины 0. |
| 2. dataset и числовой id | строка | `dataset.taskId: 23 string`, `Числовой id: 23` | `dataset` хранит строки; перед сервисом id преобразуется через `Number`. |
| 3. Статический NodeList | старая длина не изменится | `Старый NodeList: 1` оба раза, `Новый querySelectorAll: 2`, затем `3` | Сохранённая коллекция не обновляется; нужен новый запрос. |
| 4. Строка с HTML | текст без форматирования | заголовок показывает `<strong>Это текст, а не HTML</strong>` как текст | `textContent` не разбирает HTML, элемент `strong` не создан. |
| 5. Распространение события | обработчик кнопки и контейнера | `1. phase=1; target=lab-label; currentTarget=lab-card`, `2. phase=3; … currentTarget=lab-button`, `3. phase=3; … currentTarget=lab-card` |  Захват идёт сверху вниз, обработчики — на всплытии; `target` — исходный `span`, `currentTarget` — элемент с обработчиком. |
