## 4. Задание 1 — файл в двух средах

`hello.js` запущен командой `node practice-01/js/hello.js` (вывод в терминале) и через `index.html` в браузере (вывод в Console). Первые четыре строки одинаковые, последняя различается: в Node.js `Тип document: undefined`, в браузере `Тип document: object`. Причина: браузер предоставляет DOM и объект `document`, обычный запуск в Node.js не создаёт страницу. Результат в обеих средах появился в консоли, а не на странице.

## 5. Задание 2 — типы и преобразования

| Выражение | Ожидание до запуска | Факт | Тип | Объяснение |
|---|---|---|---|---|
| `"8" + 2` | 10, number | `82` | string | Операнд-строка превращает `+` в конкатенацию. |
| `"8" - 2` | NaN | `6` | number | У `-` нет строкового смысла, строка приводится к числу. |
| `Number("8") + 2` | 10 | `10` | number | Явное преобразование перед сложением. |
| `"12" > "3"` | true | `false` | boolean | Две строки сравниваются посимвольно: `"1" < "3"`. |
| `12 === "12"` | false | `false` | boolean | Строгое равенство не приводит типы. |
| `Number("")` | NaN | `0` | number | Пустая строка даёт 0, поэтому `Number()` — не проверка ввода. |
| `Number("text")` | NaN | `NaN` | number | Непреобразуемая строка даёт NaN. |
| `Boolean("false")` | false | `true` | boolean | Любая непустая строка — истинное значение. |
| `typeof null` | `"null"` | `"object"` | string | Историческая особенность `typeof`; тип самого результата — string. |
| `typeof NaN` | не число | `"number"` | string | NaN — числовое значение; тип результата выражения — string. |

## 8. Задание 5 — отладка

Исходный вывод до исправления: `Выполнено: 32`, `Осталось: -24`, `Контрольная сумма: 6`. Программа не падала, но результат был неверным.

| Ошибка | Что наблюдалось | Причина | Исправление | Результат |
|---|---|---|---|---|
| Обработка количеств | Выполнено 32, осталось -24 | `"3" + "2"` — конкатенация строк | `Number(completedText) + Number(additionalText)`, `Number(plannedText) - completedTotal` | Выполнено: 5, Осталось: 3 |
| Граница цикла | Контрольная сумма 6 | Условие `taskNumber < 4` останавливает цикл на 3 | `taskNumber <= 4` | Контрольная сумма: 10 |

Точка останова поставлена на строке вычисления `completedTotal`: в Scope видно, что `completedText` и `additionalText` — строки `"3"` и `"2"`; после Step over `completedTotal` — строка `"32"`.
